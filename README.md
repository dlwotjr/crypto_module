# KCMVP Cryptographic Module

A KCMVP-compliant (Korean Cryptographic Module Validation Program) shared library implementing the **ARIA block cipher** (Korean national standard, RFC 5794) and **SHA-3 / HMAC-SHA3** (FIPS 202 / FIPS 198-1).

KCMVP is the Korean equivalent of FIPS 140-2. The module enforces a state machine, pre-selftest (software integrity check), and algorithm KAT (Known Answer Test) self-tests before any cryptographic operation is permitted.

## Build

**Requirements:** GCC, GNU Make

```bash
# Build everything (library + demo app + SHA-3 validation program)
make

# Build only the shared library
make build/libkcmvp_crypto.so

# Remove all build artifacts
make clean
```

All output is placed in `build/`.

## Run

All commands must be run from the **project root** so that vector paths resolve correctly.

### Demo application

Runs the KCMVP initialization (pre-selftest + KAT self-test), an ARIA smoke test, the full ARIA KAT suite, and a SHA-3 / HMAC-SHA3 demonstration.

## Module State Machine

`KCMVP_Initialize()` drives the module through the following states stored in `gCryptoState`:

```
KCMVP_CM_LOAD
    └─► KCMVP_CM_PRE_SELFTEST  (integrity check)
            ├─► KCMVP_CM_CRITICAL_ERROR  (on failure)
            └─► KAT self-test
                    ├─► KCMVP_CM_CRITICAL_ERROR  (on failure)
                    └─► KCMVP_CM_NORMAL          (ready for use)
```

Every exported crypto API checks the module state and the per-algorithm KAT flag (`IS_ALG_TESTED`) before operating.

## Public API

Include `include/kcmvp.h` and link against `build/libkcmvp_crypto.so`.

| Function | Description |
|---|---|
| `KCMVP_Initialize()` | Initialize module, run pre-selftest and KAT |
| `KCMVP_GetState()` | Return current module state |
| `KCMVP_ARIA_Crypt()` | ARIA encrypt/decrypt (ECB / CBC / CTR) |
| `KCMVP_ARIA_EncKeySetup()` | Expand encryption round keys |
| `KCMVP_ARIA_DecKeySetup()` | Expand decryption round keys |
| `KCMVP_SHA3_Hash()` | One-shot SHA-3 hash (224 / 256 / 384 / 512) |
| `KCMVP_HMAC_SHA3()` | HMAC-SHA3 (224 / 256 / 384 / 512) |
